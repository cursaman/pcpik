# PC픽 (pcpik)

FHD · QHD · 4K 게이밍 완제품 PC의 주요 사양과 국내 판매가를 비교하는 Next.js 웹앱입니다.

## 실행

Node.js 20.9 이상이 필요합니다.

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 을 엽니다. 프로덕션 빌드는 `npm run build`로 확인합니다.

## 가격 데이터

`app/catalog.js`에 제품별 사양, 참고가, 웹 자료 수집 시점, 다나와 상품 코드가 들어 있습니다. 참고가는 수동 갱신하며 상품 링크에서 현재 표시 가격을 확인할 수 있습니다. 자동 수집이나 API 키 없이 실행됩니다. 상품 데이터 갱신 시 페이지의 조사 날짜도 함께 수정하세요.
